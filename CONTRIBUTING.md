# Contribuir a ALASTHEO

## Flujo

1. Continúa la rama y el PR existentes cuando el trabajo ya esté abierto; para un trabajo independiente, crea una rama desde `main`.
2. Realiza un cambio coherente y acotado.
3. Conserva fuentes, exports y evidencia en sus carpetas correspondientes.
4. Ejecuta las validaciones disponibles antes de integrar.
5. Actualiza el Pull Request existente o abre uno para un trabajo independiente, explicando el cambio y su evidencia.

## Para cambios 3D

Incluye cuando sea posible:

- versión anterior y nueva;
- archivo fuente;
- export `.glb`;
- vistas frontal, lateral y 3/4;
- cambios principales;
- problemas conocidos;
- resultado de validaciones automáticas.

## No incluir

- cachés locales;
- entornos virtuales;
- backups automáticos de Blender;
- archivos temporales del sistema;
- duplicados con nombres ambiguos.

La fusión de código/documentación no aprueba un modelo. Alpha está protegido por SHA; COPOX requiere investigación vigente antes de cada técnica nueva, tres candidatos hermanos y revisión visual. Las mutaciones de modelos no se promocionan automáticamente.
