# Referencias visuales maestras

Este directorio es el **índice visual de referencia de ALASTHEO**. Las imágenes originales se conservan en `Klymapo/alth-meta/refs/` para evitar duplicar binarios pesados y perder trazabilidad. Aquí se documenta qué referencia manda, dónde vive y para qué se usa.

## Jerarquía de autoridad

Cuando dos fuentes parezcan contradecirse, usar este orden para Theo:

1. **Hoja de 4 vistas** — silueta, volumen, colocación, perfil, espalda y 3/4.
2. **Referencia individual de Theo** — identidad, cara, expresión, pelo y vestuario.
3. **Especificaciones y medidas** — cotas exactas y límites técnicos.
4. **Renders/modelos intermedios** — sirven como evidencia del estado actual, nunca como objetivo visual.

Para Detective, su referencia individual manda sobre cualquier derivación automática desde Theo. Theo puede reutilizarse como base de lenguaje de formas y proporciones generales, pero no debe borrar edad, silueta, rostro o vestuario propios del Detective.
