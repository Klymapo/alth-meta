# SAM 3D · Theo

En la rama `sam3d-proporciones-theo` de `alth-meta` existen **11 reconstrucciones GLB** de Theo generadas con el demo de Meta (SAM 3D Objects / SAM 3D Body), además de vistas PNG y un Excel de medidas.

Fuente histórica: https://github.com/Klymapo/alth-meta/tree/sam3d-proporciones-theo/refs/sam3d/theo

## Uso correcto

Estas reconstrucciones **no son assets finales**: vienen normalizadas a una caja unitaria, no tienen escala real, no están segmentadas y no tienen rig. Se conservaron para estudiar proporciones y profundidades aproximadas.

Cinco reconstrucciones se usaron como candidatas para alturas/anclas; otras se descartaron o quedaron sin filtrar. Una reconstrucción se excluyó porque un pico de pelo alteraba el punto más alto de la caja y descalibraba toda la normalización.

## Limitación clave

No fue posible aislar con confianza el ancho del torso cuando brazo y torso forman una superficie continua en una pose con brazos abajo. Para ese tipo de medición hace falta una referencia con separación visible de extremidades, por ejemplo una A-pose leve.

Estado: **referencia experimental de proporción**, nunca autoridad visual ni modelo listo para producción.
