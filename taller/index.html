Paso 0Tu llave de GitHub
›

Se necesita un fine-grained personal access token de GitHub, limitado solo a este repositorio. Créalo en github.com/settings/personal-access-tokens/new: "Only select repositories" → alth-meta → en Permissions, pon "Read and write" en Actions, Contents e Issues. Ponle una fecha de vencimiento (90 días está bien) y renuévalo cuando expire.

El token se guarda solo en este teléfono (en el navegador), nunca se manda a ningún lado más que a la API de GitHub.

AjustesMotores de IA
›

Así son, hoy, las opciones gratis que puede usar el bucle. No está Claude: su API no es gratis (por eso existe todo esto), aunque su chat web sí lo es si algún día quieres armar un paquete a mano en vez de automático.

  • Gemini — ve imágenes (la hoja, la referencia, las siluetas), por eso da la mejor corrección. Cuota generosa, se reinicia a medianoche hora del Pacífico.
  • Groq — muy rápido y con más usos al día, pero NO ve imágenes (solo el texto de medidas y silueta). Buen respaldo cuando Gemini se topa.
  • OpenRouter — catálogo grande de modelos gratis, pero cambian de nombre seguido; por eso no está en la cadena automática. Si lo usas, revisa que el modelo siga vigente.
  • DeepSeek — su chat web es gratis, pero su API cobra desde la primera llamada; úsalo solo si te interesa pagar por velocidad/calidad.
  • Personalizado — cualquier otro servicio compatible con la API de OpenAI (otro proveedor nuevo que salga, tu propio servidor, etc.), con su URL y clave.

Se guarda en este teléfono y se usa como valor de partida en "Lanzar una corrida" y en "Asset desde una foto". Los nombres de modelo cambian seguido — si uno deja de funcionar, borra este campo para volver al de fábrica, o escribe el nuevo aquí.

BucleLanzar una corrida
›

Corre el asset que ya tiene build.py a través de tools/bucle.py en GitHub Actions. "auto" en la rama de partida sigue desde tu última corrida de ese asset. "auto" en proveedor prueba Gemini y, si se topa con la cuota del día, brinca solo a Groq — revisa "Corridas recientes" para ver cuál respondió y, si los dos fallaron, cuándo se libera cada cuota (Gemini a medianoche hora del Pacífico, Groq a medianoche UTC).
