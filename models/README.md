# Models

Archivos 3D del proyecto.

```text
models/
├─ source/<personaje>/     # fuentes editables, p. ej. .blend
├─ exports/<personaje>/    # entregables, p. ej. .glb
└─ previews/<personaje>/   # renders y vistas de revisión
```

Mantén la misma versión entre fuente, export y preview cuando pertenezcan a la misma iteración.
